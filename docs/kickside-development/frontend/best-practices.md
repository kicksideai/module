# Frontend Practices

KickSide keeps frontend implementation guidance in the current Wippy documentation.
Start with the [KickSide frontend source-of-truth directive](../07-frontend-and-web-components.md), which records KickSide shell, build, realtime, navigation, and theme requirements and links to the official Wippy pages. Query the `wippy.frontend` KB before frontend work and verify drift-sensitive behavior against those pages.
